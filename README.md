Organ Care Platform

A Django-based web application to manage organ donors and recipients and facilitate organ matching efficiently.

Features

Add and view donors

Add and view recipients

Match organs between donors and recipients

Technologies

Python

Django

HTML/CSS

SQLite

Project Structure

config/ – Django project configuration

core/ – Main app containing models and views

manage.py – Django management script

requirements.txt – Python dependencies
